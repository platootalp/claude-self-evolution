# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**self-evolution** is a Claude Code plugin that automatically extracts reusable workflows from conversations and converts them into skills. It runs in companion-mode (background `claude -p` process) and enforces hard-gated security scanning before any skill writes.

## Build & Test Commands

```bash
npm run build    # esbuild bundle → dist/runtime.mjs
npm test         # vitest run
npm run test:watch  # vitest with watch mode
```

**Entry point**: `dist/runtime.mjs` (generated by esbuild from `src/runtime.ts`)

## Architecture

```
src/
├── runtime.ts          # Command router — all CLI commands pass through here
├── types.ts           # Shared TypeScript interfaces
├── commands/          # 7 command handlers (session-start, post-tool-use, stop-gate, security-scan, review-context, log-decision, status)
└── lib/               # Core libraries (state, config, logger, security, spawner, transcript)

hooks/hooks.json       # Hook definitions → runtime.mjs commands
agents/skill-reviewer.md  # Thin forwarder agent for companion-mode review
commands/             # User-facing slash commands (/evolve-review, /evolve-status)
prompts/              # Companion agent prompt templates
skills/               # Meta-skill (evolve-skill-writer) for SKILL.md generation
```

### Runtime Commands (all routed through `runtime.mjs`)

| Command | Trigger | Purpose |
|---------|---------|---------|
| `session-start` | SessionStart hook | Diagnostic log on startup |
| `post-tool-use` | PostToolUse hook | Increment tool call counter, set `pending_review` at threshold |
| `stop-gate` | Stop hook | Consume pending_review, spawn detached `claude -p` companion process |
| `security-scan` | Called by reviewer before Write | Scan path + content, return `{allowed, reason?}` |
| `review-context` | Called by companion agent | Return transcript summary + existing skills list |
| `log-decision` | Called by reviewer after decision | Log CREATED/UPDATED/SKIPPED to JSONL + stats |
| `status` | `/evolve-status` command | Show sessions and job history |

### Multi-Platform Support

Self-evolution runs on three platforms via a PlatformAdapter interface:

| Platform | Manifest | Hooks | Companion CLI | Skill Dirs |
|----------|----------|-------|---------------|------------|
| Claude Code | `.claude-plugin/` | `hooks/hooks.json` | `claude -p` | `~/.claude/skills/` |
| Codex | `.codex-plugin/` | `hooks/hooks.codex.json` | `codex exec` | `~/.agents/skills/`, `~/.claude/skills/` |
| Cursor | `.cursor-plugin/` | `hooks/hooks.cursor.json` | `agent -p` | `~/.cursor/skills/`, `~/.claude/skills/`, `~/.agents/skills/` |

Platform detection: `CURSOR_PROJECT_DIR` → cursor, `CODEX_SESSION_ID` → codex, `CLAUDE_PLUGIN_ROOT` → claude-code, default → claude-code.

All platforms share the same `dist/runtime.mjs` bundle. Use `scripts/package.sh` to create platform-specific packages.

### Key Design Decisions

- **TypeScript + esbuild**: Single-file bundle (`dist/runtime.mjs`) — no shell script dependencies
- **Pure command hooks**: All hooks use `type: "command"`, no in-session agents blocking the main session
- **Companion mode**: Stop hook spawns `claude -p` as detached background process
- **Security at write-time**: Scanning happens inside the reviewer agent flow, not via global PreToolUse hook

## Security Model

The `security-scan` command enforces:
- **Path whitelist**: Only `~/.claude/skills/<name>/SKILL.md` is writable
- **Content scanning**: Prompt injection, dangerous bash, secrets, base64 attacks, size limits

Called by reviewer: `node runtime.mjs security-scan --path <path> --content <content>`

## Plugin Structure

Uses Claude Code plugin manifest v2 format:
- Components: `agents`, `commands`, `hooks`, `skills`
- `agentsPath`, `commandsPath`, `hooksPath`, `skillsPath` in `plugin.json`

## Data Locations

- **Plugin data**: `~/.claude/plugins/data/self-evolution-self-evolution-marketplace/`
- **Sessions**: `~/.claude/plugins/data/.../sessions/` (JSONL logs)
- **Stats**: `~/.claude/plugins/data/.../stats.json`
- **State**: `~/.claude/plugins/data/.../state.json`
